# Внешнее рецензирование кода

## Документ, передаваемый на внешнее рецензирование

На внешнее рецензирование передаётся документ в формате JSON со следующими полями:

```jsonc
{
    "uuid": "UUID", // уникальный идентификатор
    "purpose": "review|user_help|judge_help", // цель рецензирования
    "language_hint": "MARKDOWN TEXT", // рекомендации по рецензированию для языка программирования
    "contest_hint": "MARKDOWN TEXT",   // рекомендации по рецензированию на уровне турнира
    "problem_statement": "MARKDOWN TEXT", // условие задачи
    "source_language": "PROG LANG", // язык программирования исходного кода
    "source_code": "CODE", // исходный код
    "interface_language": "NAT LANG", // язык, на котором ожидается ответ
    "problem_hint": "MARKDOWN TEXT",   // общие рекомендации по рецензированию задачи
    "problem_review_hint": "MARKDOWN TEXT", // дополнительные рекомендации для рецензирования задачи
    "problem_help_hint": "MARKDOWN TEXT", // дополнительные рекомендации по подсказкам (user_help)
    "problem_judge_help_hint": "MARKDOWN TEXT", // доп рекомендации по judge_help
    "compiler_messages": "TEXT", // сообщения об ошибках/предупреждениях компилятора
    "report": {} // отчёт о тестировании задачи
}
```

## Результат внешнего рецензирования

```jsonc
{
    "uuid": "UUID", // уникальный идентификатор
    "recommended_status": "accept|reject|disqualify",
    "result": "MARKDOWN TEXT",
    "judge_result": "MARKDOWN TEXT", // в review и user_help - часть только для judge
    "agent": "STRING", // строка, идентифицирующая клиента, выполнившего ревью
    "statistics": "STRING", // строка статистической информации, на усмотрение клиента
    "input_tokens": 100, // количество потраченных input token
    "cached_input_tokens": 100, // количество потраченных cached input tokens
    "output_tokens": 100, // потраченные токены
    "reasoning_tokens": 100, // потраченные токены
    "total_tokens": 100, // общее количество токенов
    "model": "STRING", // название модели 
}
```

Если какая-либо информация недоступна, соответствующий атрибут должен отсутствовать.
