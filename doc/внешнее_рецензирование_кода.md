# Внешнее рецензирование кода

## Получение списка посылок, готовых к рецензированию

Получение списка посылок для внешнего рецензирования выполняется с помощью GET-запроса
`list-reviews-json`. В заголовке запроса должен передаваться корректный
Authorization токен. Турнир, из которого может запрашивать рецензирование
данные пользователь, должен удовлетворять следующим условиям:

* Не должен быть закрытым (closed).
* К нему должен быть открыт judge-доступ с IP, с которого выполняется запрос.
* Пользователь, выполняющий запрос либо имеет глобальное полномочие `EXT_REVIEW`,
  либо имеет полномочие `EXT_REVIEW` в данном турнире.

В GET-запросе могут передаваться следующие параметры:

* `contest_id` &mdash; идентификатор турнира, к которому пользователь имеет доступ
  на внешнее рецензирование. Этот турнир будет использоваться для проверки прав доступа,
  а для выборки посылок на рецензирование используется параметр `contests_id`, если он задан.
  Вместо параметра запроса можно использовать заголовок `X-Contest-ID`.
* `date_mode` &mdash; формат, в котором возвращаются значения времени:
  * 0 &mdash; обычный формат ejudge: `"2026-08-12 12:00:44.123456"` (микросекундная точность, локальная временная зона);
  * 1 &mdash; ISO time (UTC): `"2026-08-10T04:39:17.123456Z"`.
  * 2 &mdash; Unix timestamp с микросекундной точностью: `1786336781.123456`;
* `count` &mdash; максимальное число посылок, возвращаемых в результате (не более 50);
* `offset` &mdash; смещение в выдаче (отсчитывается от 0).
* `contest_ids` &mdash; список турниров:
  * номера турниров перечисляются через запятую: `201,202,203`;
  * если значение равно `*` (символ asterisk) &mdash; рассматриваются все контесты, удовлетворяющие
    ограничению выше.

### Пример запроса на языке Python:

```python
HOST = "EjudgeHost"
URL = f"https://{HOST}/ej/api/v1/master/list-pending-reviews-json"
TOKEN = "YourSecretToken"

headers = {
        "Authorization": "Bearer AQAA" + TOKEN
}

data = {
    "contest_id": 551,
    "contests_ids" : "*",
    "date_mode" : 1,
}

response = requests.get(URL + '?' + urllib.parse.urlencode(data), headers = headers)
```

### Результат при успешном выполнении запроса

При успешном завершении возвращается документ по следующему образцу:

```jsonc
{
  "result": {
    "reviews": [
      {
        "contest_id": 551,
        "run_id": 2633,
        "status": 2,
        "status_str": "waiting_review",
        "purpose": 1,
        "purpose_str": "review",
        "creation_time_iso": "2026-08-10T04:57:49.994664Z",
        "review_uuid": "09675974-9478-11f1-89f2-0cc47a841776"
      }
    ]
  },
  "ok": true,
  "server_time": 1786339351,
  "action": "list-pending-reviews-json"
}
```

В качестве идентификатора внешнего рецензирования используется `review_uuid`.
Он должен передаваться во все запросы, изменяющие состояние рецензирования.

### Результат при ошибке

При ошибке возвращается документ по следующему образцу:

```jsonc
{
  "ok": false,
  "server_time": 1786338176,
  "error": {
    "num": 104,                      // код ошибки
    "symbol": "ERR_INV_PARAM",       // текстовый код ошибки
    "message": "Invalid parameter",  // текстовое описание ошибки
    "log_id": "efdc2edf"             // уникальный идентификатор ошибки для поиске в логах
  }
}
```

## Взятие посылки на рецензирование

Взятие посылки на внешнее рецензирование выполняется с помощью POST-запроса
`start-review-json`. В заголовке запроса должен передаваться корректный
Authorization токен и корректный турнир в заголовке X-Contest-ID.
Турнир, из которого может запрашивать рецензирование
данные пользователь, должен удовлетворять следующим условиям:

* Не должен быть закрытым (closed).
* К нему должен быть открыт judge-доступ с IP, с которого выполняется запрос.
* Пользователь, выполняющий запрос либо имеет глобальное полномочие `EXT_REVIEW`,
  либо имеет полномочие `EXT_REVIEW` в данном турнире.

В заголовке запроса должен передаваться Content-Type application/json и тело запроса
должно быть документом со следующими полями:

```jsonc
{
  "agent": "Agent ID String",          // некоторая строка, идентифицирующая клиента, проводящего рецензирование
  "heartbeat_status": "Status string", // некоторая строка начального состояния клиента
  "date_mode": 1                       // не обязателен, см. описание в list-reviews-json
}
```

### Пример запроса на языке Python

```python
HOST = "EjudgeHost"
URL = f"https://{HOST}/ej/api/v1/master/start-review-json"
TOKEN = "YourSecretToken"

headers = {
        "Authorization": "Bearer AQAA" + TOKEN,
        "Content-Type": "application/json",
        "X-Contest-ID": "551",
}

data = {
    "date_mode" : 1,
    "review_uuid": "2e5f2bd6-26a0-44bd-a8c9-300f11b8fb90",
    "agent" : "Review agent v0.0.1",
    "heartbeat_status": "started...",
}

response = requests.post(URL, json = data, headers = headers)
```

## Сохранение результата рецензирования

Сохранение результата внешнего рецензирования выполняется с помощью POST-запроса
`finihs-review-json`. В заголовке запроса должен передаваться корректный
Authorization токен и корректный турнир в заголовке X-Contest-ID.

В заголовке запроса должен передаваться Content-Type application/json и тело запроса
должно быть документом со следующими полями:

```jsonc
{
    "review_uuid": "UUID", // UUID рецензирования
    "date_mode": 1,        // не обязателен, см. описание в list-reviews-json
    "recommended_status": "ok|reject|disqualify|ignore|summon",
    "result": "MARKDOWN TEXT",
    "judge_result": "MARKDOWN TEXT", // в review и user_help - часть только для judge
    "agent": "STRING", // строка, идентифицирующая клиента, выполнившего ревью
    "statistics": "STRING", // строка статистической информации, на усмотрение клиента
    "input_tokens": 100, // количество потраченных input token
    "cached_input_tokens": 100, // количество потраченных cached input tokens
    "output_tokens": 100, // потраченные токены
    "reasoning_tokens": 100, // потраченные токены
    "total_tokens": 100, // общее количество токенов
    "model": "STRING", // название модели
    "ai_generation_score": 96 // [0-100] - оценка того, что код сгенерирован AI
}
```

Если какая-либо информация недоступна, соответствующий атрибут должен отсутствовать.

Обновление текущего статуса рецензирования выполняется с помощью POST-запроса
`heartbeat-review-json`. В заголовке запроса должен передаваться корректный
Authorization токен и корректный турнир в заголовке X-Contest-ID.

В заголовке запроса должен передаваться Content-Type application/json и тело запроса
должно быть документом со следующими полями:

```jsonc

    "review_uuid": "2e5f2bd6-26a0-44bd-a8c9-300f11b8fb90",
    "heartbeat_status": "performing (1%)",
}
```

## Получение одной посылки на рецензировании

Получить посылку, находящуюся на рецензировании у текущего пользователя,
можно с помощью GET-запроса `get-active-review-json`.

### Пример запроса на языке Python:

```python
HOST = "EjudgeHost"
URL = f"https://{HOST}/ej/api/v1/master/get-active-review-json"
TOKEN = "YourSecretToken"

headers = {
        "Authorization": "Bearer AQAA" + TOKEN,
        "X-Contest-ID": "551",
}

data = {
    "review_uuid": "2e5f2bd6-26a0-44bd-a8c9-300f11b8fb90",
    "date_mode" : 1,
}

response = requests.get(URL + '?' + urllib.parse.urlencode(data), headers = headers)
```

При успешном выполнении возвращается JSON-объект как в запросе `start-review-json`.
