# `enable_problem_history`

Навигация: [Система ejudge](../../система_ejudge.md)/[Использование](../../использование.md)/[Конфигурационные файлы](../../конфигурационные_файлы.md)/[serve.cfg](../../serve.cfg.md)/[Глобальные конфигурационные параметры](../global.md)/[`enable_problem_history`](enable_problem_history.md)

Если конфигурационный параметр установлен в положительное значение, то значение uuid для
задачи будет загружаться из файла `history.txt`, который должен
находиться в каталоге задачи.

Смотри также [`require_problem_uuid`](../global/require_problem_uuid.md),
[`uuid`](../problem/uuid.md).

Поддерживается с версии [3.8.0](../../change/изменения_в_версии_3.8.0.md).
