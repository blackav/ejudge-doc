# `uuid`

Навигация: [Система ejudge](../../система_ejudge.md)/[Использование](../../использование.md)/[Конфигурационные файлы](../../конфигурационные_файлы.md)/[serve.cfg](../../serve.cfg.md)/[Конфигурационные параметры задач](../problem.md)/[`uuid`](uuid.md)

Этот конфигурационный параметр позволяет задавать GUID задачи. GUID задачи хранится в базе данных посылок с каждой задачей
и предназначен для того, чтобы идентифицировать одну и ту же задачу под разными именами в одном турнире или
нескольких турнирах. То есть с помощью GUID задачи можно получить все посылки по данной задаче во всех турнирах.

Пример:

```text
[problem]
uuid = "18ea093d-a44a-4a02-827a-da56d1e2a838"
```

Чтобы не копировать GUID задачи из конфигурационного файла в конфигурационный файл можно сохранить его один раз в файле
history.txt в каталоге задачи и установить параметр [`enable_problem_history`](../global/enable_problem_history.md).

Смотри также [`enable_problem_history`](../global/enable_problem_history.md),
[`require_problem_uuid`](../global/require_problem_uuid.md).

Поддерживается начиная с версии
[3.8.0](../../change/изменения_в_версии_3.8.0.md)
