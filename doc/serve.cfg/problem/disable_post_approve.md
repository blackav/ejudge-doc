# `disable_post_approve`

Навигация: [Система ejudge](../../система_ejudge.md)/[Использование](../../использование.md)/[Конфигурационные файлы](../../конфигурационные_файлы.md)/[serve.cfg](../../serve.cfg.md)/[Конфигурационные параметры задач](../problem.md)/[`disable_post_approve`](disable_post_approve.md)

Если данная конфигурационная переменная установлена в положительное
значение,
и включено [внешнее рецензирование посылок](../../внешнее_рецензирование_посылок.md),
отключается пост-модерация результатов внешнего рецензирования, и рецензия будет
доступна пользователям немедленно после окончания рецензирования.

Пример.

```text
[problem]
# ...
enable_external_review
disable_post_approve
```

Поддерживается начиная с версии [3.15.0](../../change/изменения_в_версии_3.15.0.md).
