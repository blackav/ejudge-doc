# `enable_external_review`

Навигация: [Система ejudge](../../система_ejudge.md)/[Использование](../../использование.md)/[Конфигурационные файлы](../../конфигурационные_файлы.md)/[serve.cfg](../../serve.cfg.md)/[Конфигурационные параметры задач](../problem.md)/[`enable_external_review`](enable_external_review.md)

Если данная конфигурационная переменная установлена в положительное
значение, то в задаче будет поддерживаться
[внешнее рецензирование посылок](../../внешнее_рецензирование_посылок.md).

Значение конфигурационной переменной наследуется из абстрактных задач.

Пример.

```text
[problem]
# ...
enable_external_review
```

Поддерживается начиная с версии [3.15.0](../../change/изменения_в_версии_3.15.0.md).
В версии 3.15.0 рецензирование реализовано _не полностью_.
