# `enable_user_help_request`

Навигация: [Система ejudge](../../система_ejudge.md)/[Использование](../../использование.md)/[Конфигурационные файлы](../../конфигурационные_файлы.md)/[serve.cfg](../../serve.cfg.md)/[Конфигурационные параметры задач](../problem.md)/[`enable_user_help_request`](enable_user_help_request.md)

Если данная конфигурационная переменная установлена в положительное
значение,
и включено [внешнее рецензирование посылок](../../внешнее_рецензирование_посылок.md),
участник турнира получит возможность отправлять запросы на помощь в решении задачи.
Посылка не должна пройти все тесты, то есть иметь статус Compilation error, Partial solution
и т. п.

Значение конфигурационной переменной наследуется из абстрактных задач.

Пример.

```text
[problem]
# ...
enable_external_review
enable_user_help_request
```

Поддерживается начиная с версии [3.15.0](../../change/изменения_в_версии_3.15.0.md).
