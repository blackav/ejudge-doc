# `disable_pre_moderation`

Если данная конфигурационная переменная установлена в положительное
значение,
и включено [внешнее рецензирование посылок](../../внешнее_рецензирование_посылок.md),
отключается премодерация запросов на внешнее рецензирование, и запросы на внешнее
рецензирование станут доступными внешним инструментам немедленно.

Пример.

```text
[problem]
# ...
enable_external_review
disable_pre_moderation
```

Поддерживается начиная с версии [3.15.0](../../change/изменения_в_версии_3.15.0.md).
__В версии 3.15.0 опция `disable_pre_moderation` должна быть установлена, так как шаг премодерации посылок не реализован!__
